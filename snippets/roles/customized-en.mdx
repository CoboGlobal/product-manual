In addition to the preset user roles provided by Cobo, you can also create your own customized user roles.

## Role types in Cobo Portal

Cobo Portal shows whether each role is **Default** or **Customized** in the role list. **Default** roles are system-provided roles. **Customized** roles are user-created roles. Use the **Type** column or **Type** filter to identify each role type.

To create a new user role, click your profile avatar in the top-right corner, choose **Organization**, click the **User Roles** tab, then click **Create User Role**.

<img src="/en/images/organization/org9.png" className="screenshot_modal"/>

**Note**: In the **Create New User Role** dialog, please specify whether this user role will apply to web operations or API operations.
