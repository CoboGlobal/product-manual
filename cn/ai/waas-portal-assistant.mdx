Cobo Portal AI 助手为受支持的 WaaS 问题和流程提供统一的对话入口。单一的 **WaaS Portal Agent** 会根据您的请求判断所需能力，您不需要在多个 Agent 之间选择或切换。

助手仅在当前团队和您的角色权限范围内工作。可用能力可能因环境、账户权限和灰度发布状态而不同。

## 打开助手

1. 使用符合条件的账户登录 [Cobo Portal](https://portal.cobo.com/login)。
2. 点击圆形 **AI** 图标，打开全页面 AI 助手。
3. 使用自然语言描述问题或任务。

对话界面包含：

| 控件 | 用途 |
| --- | --- |
| 输入框 | 使用中文或英文提问或描述任务 |
| `/` | 快速联系客户支持、销售团队或获取套餐建议 |
| `+` | 添加截图或其他相关上下文 |
| 会话列表 | 查看并继续之前的对话 |

## 描述您的目标

说明要完成的任务，并提供已知的标识符或参数。助手会在操作前确认对象；信息不足时会继续询问，而不会猜测。

示例：

- “从我的 MPC 钱包提取 10 USDT 到 0xabc...”
- “交易 abc123 为什么被拒绝？”
- “邀请 teammate@company.com 加入团队，角色为 Viewer。”
- “给这个 MPC 钱包添加 Solana。”
- “按链显示团队的总资产。”

## 支持的任务

### 产品、API 和问题排查

询问 Cobo 功能的使用方式、WaaS 2.0 API 集成方法、错误含义，或支持的链和代币。助手会根据 Cobo 产品手册和 Developer Hub 文档回答。

### 钱包和充币地址

列出钱包、创建受支持的钱包，或生成充币地址。对于 MPC 钱包，助手可以协助完成从 Vault 和签名人设置，到 KeyGen、备份状态检查、钱包创建以及启用受支持链的流程。

KeyGen、私钥分片备份和部分审批仍需在 Portal Mobile 或 Cobo Guard 中完成。助手不会显示或导出私钥材料。

### 交易和转账

助手可以：

- 查找和筛选交易记录。
- 在准备转账前估算费用并完成必要校验。
- 诊断指定交易处于待处理、被拒绝或失败状态的原因。
- 为现有交易准备受支持的处理操作，例如加速、取消、RBF 取消（Drop）或重发。

在提交转账或变更现有交易前，助手会确认交易、操作类型和相关费用。最终授权仍需按照适用的 Portal Mobile 或 Cobo Guard 流程完成。

### 成员和角色

邀请成员，并分配一个或多个可用角色。只有完成必要的确认、MFA 和审批流程后，邀请才会生效。

### 交易策略

查看现有交易策略，并获取有关策略类型、条件、审批要求、限额和优先级的配置建议。

<Warning>助手不能在对话中创建、修改、调整顺序或启用交易策略。请在 Cobo Portal 中完成策略变更，然后让助手检查变更后的配置。</Warning>

### 审批状态

查看审批请求、尚未确认的审批人，以及需要在哪里完成确认。

<Warning>助手不能代替其他用户批准、拒绝或撤销请求。每位审批人必须在自己的 Portal Mobile 或 Cobo Guard 中完成操作。</Warning>

### 资产和活动

查询团队级汇总数据和图表，包括按代币、链或钱包类型拆分的资产，余额历史，以及充币或提币趋势。

### 客户支持和安全检查

助手可以查看或准备支持工单、检查是否存在重复问题，并协助填写提交表单。它还可以根据受支持的安全检查项，检查团队、成员、MPC 钱包、API Key、Webhook 和交易策略配置。

## 确认与授权

助手会区分信息查询和会改变数据或资产的操作：

| 任务类型 | 处理方式 |
| --- | --- |
| 产品解释和只读查询 | 助手获取权限范围内的信息并解释结果 |
| 转账、成员邀请、MPC 设置和交易处理 | 助手确认对象和参数，然后准备受支持的操作 |
| MFA、审批、签名和 KeyGen | 您在 Cobo Portal、Portal Mobile 或 Cobo Guard 中完成必要步骤 |

助手不会绕过权限、交易策略、治理策略、MFA、审批或签名要求。

## 能力限制

助手不能：

- 在未经确认的情况下执行关键资产或配置操作。
- 代替审批人批准或拒绝请求。
- 在对话中创建或修改交易策略。
- 访问或泄露私钥、助记词、私钥分片、API Secret 或签名值。
- 访问其他团队或超出您角色权限的数据。
- 提供专业的金融、法律、税务或合规建议。
- 保证所有信息在任何情况下都完整或实时。

## 联系客户支持或销售团队

使用斜杠命令，或直接说明您的需求：

| 快捷方式 | 用途 |
| --- | --- |
| `Contact support` 或 `/human_support` | 由 Cobo 客服在当前对话中继续处理 |
| `/contact_sales` | 打开联系 Cobo 销售团队的页面 |
| `/plan_recommendation` | 开始套餐推荐对话 |

有关通用的数据使用和安全说明，请参阅 [Cobo AI 简介](/cn/ai/introduction)。
