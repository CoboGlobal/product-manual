Webhooks 和 Callbacks 是 WaaS 服务与您的 App 通信的重要机制。当您设置并注册 Callback Endpoint 和 Webhook Endpoint 后，WaaS 服务会在事件发生时向指定的 URL 发送推送消息。它们让您的 App 接收实时更新或通知，并相应地响应事件。

Callback 类似于双因素身份验证 (Two Factor Authentication, 2FA) 方式。注册 Callback Endpoint 后，您的 App 可以在提币、合约调用等敏感 WaaS 2.0 API 操作继续执行前进行二次确认。

<Warning>如果 API Key 未配置 Callback Endpoint，基于 Callback 的提币二次确认将不会执行，提币请求会默认批准。</Warning>

有关 Webhooks 和 Callbacks 机制以及如何处理它们的详细信息，请参阅 [Webhooks and callbacks](https://www.cobo.com/developers/v2_cn/guides/webhooks-callbacks/introduction)。
