**交易记录**页把费用中心里所有的资金进出收在同一张表里——手续费、账单、充值不再分散在多张表中。

## 记录分组

记录按性质分为三组：

| 分组 | 包含 |
|---|---|
| **交易手续费** | 您的钱包发起交易所产生的链上手续费，以及这些手续费的退还 |
| **Cobo 账单** | Cobo 月度账单及其退费 |
| **充值** | 您向费用中心充入的资金 |

在分组内部，**类型**列进一步说明每一条记录：*钱包 Gas 费*、*钱包 Gas 费退费*、*Cobo 账单*、*Cobo 退费*、*充值* 或 *其他*。

手续费记录还会标明是从哪种余额扣的——*（Credits 支付）* 或 *（Gas 代币支付）*。想确认某条链究竟用了自己的代币、还是回落到 Credits，看的就是这个字段。

充值记录则展示**充值币种**与**入账**两列，说明这笔钱最终进入了哪种余额：**Credits** 或 **Gas 代币**。

## 状态

| 状态 | 含义 |
|---|---|
| **已完成** | 已结算。对充值而言，资金已可使用。 |
| **处理中** | 仍在进行中。处于该状态的充值尚未计入余额。 |
| **已拒绝** | 未能完成。对充值而言，资金没有入账，请联系 help@cobo.com。 |

## 筛选记录

- **时间范围**——近 7 天、近 30 天、近 90 天或自定义。**最长可查询 12 个月。**
- **筛选**——按**状态**、**链**、**类型**收窄。筛选面板是草稿式的：选好后点击**应用筛选**才生效，**重置**可清空。筛选按钮上的数字表示当前生效了几个条件。
- **只看异常记录**——只展示未正常完成的记录。
- **搜索**——按记录 ID 搜索，或按记录 ID 与交易哈希搜索，具体取决于您所在的分组。

点击任意行的**查看详情**可打开详情抽屉。

## 查看记录详情

抽屉展示该记录的基本信息：

| 字段 | 含义 |
|---|---|
| **记录 ID** | 该条记录的唯一标识，也是对账用的主键 |
| **关联业务单号** | 产生这条记录的业务操作，例如引发该手续费的那笔交易 |
| **状态** | 已完成、处理中或已拒绝 |
| **发起方** | 对充值而言，说明资金的来路：*链上充值* 或 *法币充值* |
| **创建时间** / **更新时间** | 记录创建与最近变更的时间 |
| **来源** / **目标** | 相关地址 |
| **金额** | 以原币种表示的金额 |
| **退款原类型** | 退款记录对应的原始类型：*Credits 支付*、*Gas 代币支付* 或 *Cobo 账单* |

<Note>抽屉只以单个值展示记录的当前状态，不提供逐步推进的状态时间线，处理中的充值也不显示区块确认进度。</Note>

## 导出对账

点击**导出**打开**导出交易记录**。

1. 选择**时间范围**：全部、上个月或自定义。
2. 如果出现该步骤，选择**费用类型**：**Credits** 或 **Gas 代币**。
3. 点击**生成导出文件**。

<Note>
**导出入口只在「交易手续费」和「充值」两个分组下提供。** **Cobo 账单**分组没有导出按钮，账单请到[账单与套餐](/cn/portal/billing-center/bills-and-plans)页用**导出全部账单**导出。

**只有开启了 Gas 代币充值，才会出现「费用类型」这一步。** 否则费用类型只有 Credits 一种，弹窗会直接跳过该选择。

出现该步骤时，它是必选项，不能跳过：Credits 记录与 Gas 代币记录是分开导出的，因此一个同时涉及两者的时间段需要导出两次，再由您自行合并。
</Note>

导出在后台异步生成。**最近导出**列出您的导出任务，包含**范围**、**请求时间**与**状态**——*生成中*、*已完成*、*生成失败* 或 *已取消*，任务就绪后可**下载**。列表**最多保留 10 条**，需要长期留存的文件请及时下载。

### 与账单对账

交易手续费是实时扣除的，**不计入** Cobo 月度账单；账单覆盖的是套餐费与超额费用——两者需要分别对账。

界面上没有从账单跳转到其关联手续费记录的入口。要把两者对应起来，请先在[账单与套餐](/cn/portal/billing-center/bills-and-plans)中查看该账单的账单周期，再在本页设置相同的时间范围并导出。
