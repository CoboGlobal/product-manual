**账单与套餐**页管理的是您的订阅：当前是什么套餐、用掉了多少、以及 Cobo 出了哪些账单。

<Note>账单与发票只对具备相应权限的角色可见。如果该页签显示为空或受限，请联系组织管理员。</Note>

## 您的订阅

套餐是**按钱包类型**分别持有的——MPC 钱包、全托管钱包、交易所钱包、智能合约钱包各有各的套餐与状态，因此同一个组织在不同钱包类型上可以处于不同档位。

针对每一种，看板会在**当前套餐**标签下展示套餐名称、适用的钱包类型、**套餐到期日**与**服务周期**。

## 资源用量

**资源用量**按指标逐张卡片展示当前套餐额度的消耗情况：

| 指标 | 统计的是 |
|---|---|
| **累计提币金额** | 已转出的金额，以美元计 |
| **资产托管金额** | 托管中的资产金额，以美元计 |
| **钱包地址数** | 已使用的地址数 |
| **可用公链数** | 您可使用的公链数 |
| **API 调用次数** | 已发生的 API 调用次数 |
| **团队成员数** | 团队成员数 |

具体展示哪些卡片取决于钱包类型：智能合约钱包展示累计提币金额、资产托管金额、API 调用次数与团队成员数；交易所钱包展示累计提币金额、API 调用次数与团队成员数。

超出套餐的部分按**超额费用**计价，并计入当月账单。

## 选择套餐

套餐卡片会从 API 调用次数、资产托管金额、团队成员数、公链数与钱包地址数几个维度，对比**入门版**、**标准版**与**专业版**。计费周期分为**按月**、**半年**与**按年**。

可以先用**套餐算价器**按您预期的用量试算价格，再决定是否购买。

<Note>套餐同时决定了您能使用[设置](/cn/portal/billing-center/settings)中的哪些内容：各链代付规则与扣费口径仅**专业版**套餐可用。</Note>

购买或升级时，订单摘要会展示优惠金额、优惠券、应付金额以及您在费用中心的余额。余额不足时，摘要会显示**余额不足**并提供**充值**入口。

支付成功后套餐**立即生效**。页面所示价格为基础费用，超出部分单独计费；订阅后，系统会在每个计费周期结束时自动扣款。

## 账单历史

**账单历史**列出您的账单，包含**账单 ID / 名称**、**金额**、**账单周期**、**到期日**与**状态**——*尚未支付*、*已支付* 或 *已逾期*。

每张账单可以**去支付**、**查看详情**（打开账单文件），支付完成后还可**查看收据**。

<Note>
交易手续费**不计入** Cobo 账单。它在交易发生时就已从余额中实时扣除——账单本身覆盖的是套餐费与超额费用。

也就是说，账单与交易手续费记录是两份需要分别核对的数据。界面上没有从账单跳转到其关联手续费记录的入口，请在[交易记录](/cn/portal/billing-center/transactions)中用时间范围与导出功能自行对应。
</Note>

## 支付账单

Cobo 会在扣款日从 Credits 中自动扣款。

<Warning>
如果因 Credits 不足导致自动扣款失败，**Cobo 不会自行重试**，事后充值也不会让扣款重新发起。

请先充入足额 Credits，然后在此处点击**去支付**完成支付。[总览](/cn/portal/billing-center/overview)页的卡片只提供**充值**按钮和**账单列表**入口，支付动作本身要在本页完成。
</Warning>

在账单详情中可将账单下载为 PDF，支付完成后还可下载凭证。
