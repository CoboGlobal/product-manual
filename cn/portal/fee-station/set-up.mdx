## 为 Fee Station 充值

### 充值美元或稳定币

1. 登录 [Cobo Portal](https://portal.cobo.com/login)。
2. 点击左侧导航栏中的 **Fee Station**。
3. 打开**美元/美元稳定币**标签页。
4. 点击**总价值**旁的**充币**。
5. 选择充值方式，并按照页面提示完成操作。

    <img src="/cn/images/fee-station/deposit-u.png" className="screenshot_full_screen" alt="在 Fee Station 中充值美元或美元稳定币" />

### 充值 Gas Token

1. 登录 [Cobo Portal](https://portal.cobo.com/login)。
2. 点击左侧导航栏中的 **Fee Station**。
3. 打开 **Gas Token** 标签页。
4. 找到目标链对应的 Gas Token。
5. 点击 <img src="/cn/images/fee-station/deposit.svg" className="icon" alt="充值图标" /> 充值图标，并按照页面提示完成操作。

    <img src="/cn/images/fee-station/deposit-gas-token.png" className="screenshot_full_screen" alt="在 Fee Station 中充值 Gas Token" />

如需选择充值资产，请参阅[资金流转](/cn/portal/fee-station/fund-flows)。

## 选择链和代币

1. 在 **Fee Station** 中打开**代币**标签页。
2. 点击目标代币旁的 <img src="/cn/images/fee-station/deposit.svg" className="icon" alt="充值图标" /> 充值图标，或点击页面顶部的充值图标并选择代币。

    <img src="/cn/images/fee-station/2.png" className="screenshot_full_screen" alt="选择要充值到 Fee Station 的代币" />

3. 复制充值地址或扫描二维码。
4. 如需从 Cobo Portal 中的其他钱包转账，请点击**从其他钱包充值**，并按照[转账](/cn/portal/transfers/introduction)中的步骤操作。

## 设置付款偏好

1. 打开 **Gas Token** > **付款偏好**。
2. 展开需要配置的链。
3. 选择该链当前显示的付款偏好之一。
4. 点击**保存更改**。
5. 完成安全验证。

<img src="/cn/images/fee-station/preferences.png" className="screenshot_full_screen" alt="Fee Station 付款偏好" />

<img src="/cn/images/fee-station/1.png" className="screenshot_full_screen" alt="配置链的付款偏好" />

请分别配置 Cobo Portal 中显示的 EVM 兼容链和 TRON 选项。使用场景指南请参阅[选择 Fee Station 费用模式](/cn/portal/fee-station/choose-your-fee-model)。

<Note>白名单费用配置可能适用于特定地址。因此，这些地址的代付行为可能与此处设置的付款偏好不同。</Note>

## 查看活动

在 **Fee Station** 中，使用地址图标查看代币的充值地址，使用交易流水图标查看其活动。使用筛选、排序和搜索控件查找代币和记录。

如需通过 API 核对余额、地址和交易，请参阅[监控 Fee Station 活动](/cn/portal/fee-station/monitor-and-alerts)。

## TRON 手续费支付

对于 TRON USDT 转账，Fee Station 通过以下两种方式之一支付链上手续费：

- **Energy mode**：Fee Station 使用发送地址上可用或已租赁的能量。在能够使用能量时，Fee Station 会优先采用该模式。
- **TRX burn mode**：当无法使用能量时，Fee Station 通过燃烧 TRX 支付手续费。

显示的手续费反映该笔转账实际采用的方式。Fee Station 如何确定能量租赁成本，请参阅 [TRON 能量租赁](/cn/portal/fee-station/choose-your-fee-model#tron-能量租赁)。
