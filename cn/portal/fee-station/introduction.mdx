## 什么是 Fee Station

在多链环境中，每条区块链都要求使用不同的原生代币（Gas Token，如 ETH、TRX、SOL）来支付交易手续费。这使得企业和开发者不仅需要为每条链准备相应代币，还要频繁检查余额，稍有疏忽就可能导致交易失败。

与此同时，服务费、托管费等平台费用，也需要单独结算，往往通过邮件、表格、人工对账完成，流程复杂、效率低。

Fee Station 正是为了解决这些繁琐的管理问题而设计的。它是 Cobo 提供的一站式费用管理工具，相当于一个团队共享的费用账户：只需由团队中的任一成员为 Fee Station 账户充值，系统就能根据已配置的策略为团队内所有链上交易自动代付费用，并统一结算各类平台费用。

<Note>目前，Fee Station 支持为 MPC 钱包和 Web3 钱包在 EVM 兼容链、TRON、Solana 和 Tempo 上发起的交易自动代付链上手续费。</Note>

## 支持的钱包类型

Fee Station 仅支持为 MPC 钱包和 Web3 钱包代付链上手续费。

在 Cobo 的钱包分类中，Web3 钱包属于全托管钱包的一种子类型。全托管钱包还包括资产钱包，但资产钱包不支持手续费代付，仅可使用 Fee Station 余额结算托管费。

| 钱包类型 | 手续费代付 | 可结算的其他费用 |
| --- | --- | --- |
| [MPC 钱包](/cn/portal/mpc-wallets/introduction) | 支持 | 服务费、托管费 |
| [全托管钱包（Web3 钱包）](/cn/portal/custodial-wallets/web3-wallets/introduction) | 支持 | 服务费、托管费 |
| [全托管钱包（资产钱包）](/cn/portal/custodial-wallets/asset-wallets/introduction) | 不支持 | 托管费 |

## 谁适合使用 Fee Station

Fee Station 适用于所有希望简化链上费用管理的团队，特别是：

- 交易所或钱包服务商：集中管理和代付终端用户的链上交易 Gas，减少运维工作
- 支付服务提供商：通过一价全包或统一结算模式屏蔽链上细节，优化用户体验
- 使用 Cobo 钱包服务的企业开发者：希望通过自动化方式控制费用预算、追踪支出状态，并通过 Webhook 实时获取交易执行和余额变动等通知。

## Fee Station 能帮你做什么

### 自动代付 Gas

支持为 MPC 钱包和 Web3 钱包发起的交易自动支付链上手续费，可配置“仅在交易地址余额不足时代付”或“始终代付”等策略，减少因 Gas 不足导致的交易失败。设置完成后，系统将自动识别是否需要代付，整个过程无需人工干预。支持代付手续费的链请参考[支持的链](#支持的链)。

### 自动加油的工作方式

为确保提币地址能够支付自身的链上手续费，Fee Station 可能会在处理交易前向该地址发送少量原生 Gas Token。该笔加油费用将从您的 Fee Station 余额中扣除。根据您的配置与可用余额，即使账户中存在原生 Gas Token 余额，该笔扣费也可能从您的美元或美元稳定币余额中结算。

### 统一结算各类费用

除了支付链上交易手续费，Fee Station 的余额还可用于结算 Cobo Portal 中产生的所有平台费用，例如服务费、托管费等。你无需为每一类费用分别管理账户或准备资金，只需维护 Fee Station 中的单一余额，就能实现统一扣费、清晰记录，极大简化财务管理流程。

<Tip>
Fee Station 支持的费用类型：
- [全托管钱包（资产钱包）](/cn/portal/custodial-wallets/asset-wallets/introduction)：托管费
- [MPC 钱包](/cn/portal/mpc-wallets/ocw/introduction) / [全托管钱包（Web3 钱包）](/cn/portal/custodial-wallets/web3-wallets/introduction)：链上手续费、服务费、托管费
</Tip>

### 灵活支持多种充值方式

除了直接充值所需链的 Gas Token，你还可以选择最简单的方式：只充值美元稳定币（如 USDT、USDC）或者美元法币作为统一余额。Fee Station 可根据您的付款偏好使用这些资金支付多链手续费，减少为每条链单独准备代币的工作。支持充值的稳定币与 Gas Token 请参考[支持的代币](#支持的代币)。

### TRON 手续费优化与能量租赁

对于 TRON 交易，Fee Station 可在适用场景使用可用或租赁的能量，以减少 TRX 燃烧产生的手续费成本。当能量无法用于某笔转账时，Fee Station 退回 TRX 燃烧模式（TRX burn mode）。用户无需手动管理能量。

### 提供 API 与 Webhook 支持

Fee Station 提供标准化的 API 和 Webhook 接口，帮助你在系统中实时查看费用状态并获取通知提醒，方便对账、监控和运营分析。

如需详细接入说明，请参见 [Fee Station API 文档](https://www.cobo.com/developers/v2/api-references/feestation/get-fee-station-transaction-information)与 [Webhook 文档](https://www.cobo.com/developers/v2_cn/guides/webhooks-callbacks/webhook-event-type#webhook-事件类型)。

## 使用 Fee Station 的优势

下表展示了使用 Fee Station 前后在链上费用管理等方面的差异，帮助你直观了解其带来的优势：

| 功能维度 | 使用 Fee Station 前          | 使用 Fee Station 后                                    |
| ------------ | -------------------------------- | ---------------------------------------------------------- |
| Gas 准备     | 每条链都需要手动准备 Gas Token   | 可充值 Gas Token 或美元稳定币，统一由 Fee Station 自动代付 |
| 代付策略     | 只能人工操作                     | 可配置交易地址 Gas Token 不足时代付或始终代付                |
| 费用结算     | 多链多币种分散记录，难以统一核算 | 使用同一币种与单一账户结算各类费用，账务更直观                       |
| 失败交易     | Gas 不足导致交易失败风险高       | 自动检测并补足 Gas，显著降低失败率                         |
| 维护成本     | 人工操作频繁、耗时               | 一次配置即可自动运行，减少维护工作                         |
| 数据追踪     | 缺乏统一的费用记录               | 可在 Fee Station 导出完整充值与支出记录                    |

充值美元法币即可覆盖多链手续费与平台费用，无需准备 Gas Token，亦无需预先充值或转入数字货币资产。

## TRON 手续费概念

在通过 Fee Station 进行 TRON 链交易时，涉及多个独立的资金来源和链上机制。了解它们有助于充入正确的余额并排查手续费问题。

| 概念 | 说明 |
| --- | --- |
| **发送地址 TRX** | 发送地址中直接持有的 TRX。当 Fee Station 未启用或交易不满足代付条件时，手续费从此余额支付。 |
| **Fee Station Gas Token 余额（TRX）** | 已充入 Fee Station Gas Token 账户的 TRX。当 Fee Station 已启用且已在 **Gas Token** > **付款偏好** 中配置 TRON 策略时，此余额用于支付 TRON 手续费。充值路径：**Fee Station** > **Gas Token** > **代币**。 |
| **Fee Station 美元/美元稳定币余额** | 已充入 Fee Station **美元/美元稳定币**账户的美元或稳定币（如 TRON USDT）。该余额可根据您配置的付款偏好用于支付 TRON 手续费。充值路径：**Fee Station** > **美元/美元稳定币**。 |
| **TRON 能量与带宽** | 可减少或消除 TRX 燃烧的链上资源。Fee Station 支付 TRON 手续费时，条件允许时优先使用能量模式（Energy mode）；能量不足时退回 TRX 燃烧模式（TRX burn mode）。 |

<Note>Fee Station 不会自动将稳定币余额兑换为 TRX。每笔 TRON 交易所使用的支付路径，取决于您配置的付款偏好以及交易时 Fee Station 账户中的可用余额。</Note>
