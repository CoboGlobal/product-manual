## 什么是 Fee Station

Fee Station 是一个供团队共享的费用账户，用于支付团队范围内产生的费用。它独立于任何单个钱包的资产余额。团队中的任一成员都可以为 Fee Station 充值，系统会根据团队配置，使用共享余额为符合条件的钱包和费用类型付款。

为 Fee Station 充值不会将资产转入某个特定钱包。当符合条件的交易或账单产生时，系统会检查 Fee Station 是否已配置为该钱包或费用类型付款。如果符合条件且共享余额充足，系统会从 Fee Station 扣款，以代替钱包自身余额付款或与钱包自身余额共同完成付款。

如需了解资产如何进入 Fee Station 并在共享账户中流转，请参阅[资金流转](/cn/portal/fee-station/fund-flows)。

<Note>目前，Fee Station 支持为 MPC 钱包和 Web3 钱包在 EVM 兼容链、TRON 和 Solana 上发起的交易自动代付链上手续费。</Note>

## 支持的钱包类型

Fee Station 仅支持为 MPC 钱包和 Web3 钱包代付链上手续费。

在 Cobo 的钱包分类中，Web3 钱包属于全托管钱包的一种子类型。全托管钱包还包括资产钱包，但资产钱包不支持通过 Fee Station 代付手续费。

| 钱包类型 | Network gas |
| --- | --- |
| [MPC 钱包](/cn/portal/mpc-wallets/introduction) | 支持 |
| [全托管钱包（Web3 钱包）](/cn/portal/custodial-wallets/web3-wallets/introduction) | 支持 |
| [全托管钱包（资产钱包）](/cn/portal/custodial-wallets/asset-wallets/introduction) | 不支持 |

## 谁适合使用 Fee Station

Fee Station 适用于所有希望简化链上费用管理的团队，特别是：

- 交易所或钱包服务商：集中管理和代付终端用户的链上交易 Gas，减少运维工作
- 支付服务提供商：通过一价全包或统一结算模式屏蔽链上细节，优化用户体验
- 使用 Cobo 钱包服务的企业开发者：希望通过自动化方式控制费用预算、追踪支出状态，并通过 Webhook 实时获取交易执行和余额变动等通知。

## Fee Station 能帮你做什么

### 自动代付 Gas

支持为 MPC 钱包和 Web3 钱包发起的交易自动支付链上手续费，可配置“仅在交易地址余额不足时代付”或“始终代付”等策略，减少因 Gas 不足导致的交易失败。设置完成后，系统将自动识别是否需要代付，整个过程无需人工干预。支持代付手续费的链请参考[支持的链](#支持的链)。

### 自动加油的工作方式

为确保提币地址能够支付自身的链上手续费，Fee Station 可能会在处理交易前向该地址发送少量原生 Gas Token。该笔加油费用将从您的 Fee Station 余额中扣除。根据您的配置与可用余额，即使账户中存在原生 Gas Token 余额，该笔扣费也可能从您的美元或美元稳定币余额中结算。

### 统一结算 Gas 费用

Fee Station 的余额可用于结算所有支持的钱包类型和链上产生的 Network gas，无需为每条链分别维护 Gas 余额。各钱包类型是否符合条件，请参阅[支持的钱包类型](#支持的钱包类型)。

### 灵活支持多种充值方式

除了直接充值所需链的 Gas Token，你还可以选择最简单的方式：只充值美元稳定币（如 USDT、USDC）或者美元法币作为统一余额。Fee Station 会在交易发生时自动兑换成所需的 Gas Token，帮你覆盖多链交易的手续费，无需再为每条链分别准备代币。支持充值的稳定币与 Gas Token 请参考[支持的代币](#支持的代币)。

### TRON 手续费优化与能量租赁

Fee Station 在 TRON 链上会自动使用能量租赁（Energy Rental）机制，优先消耗能量以减少直接燃烧 TRX 的手续费成本。整个过程由 Fee Station 自动完成，用户无需手动管理能量，即可享受手续费优化效果。Fee Station 会在交易发生时请求实时能量租赁报价，并为报价添加安全缓冲，因此费用是动态变化的，并非固定的折扣比例。详情请参阅[TRON 能量租赁](/cn/portal/fee-station/choose-your-fee-model#tron-能量租赁)。

### 提供 API 与 Webhook 支持

Fee Station 提供标准化的 API 和 Webhook 接口，帮助你在系统中实时查看费用状态并获取通知提醒，方便对账、监控和运营分析。

如需详细接入说明，请参见 [Fee Station API 文档](https://www.cobo.com/developers/v2/api-references/feestation/get-fee-station-transaction-information)与 [Webhook 文档](https://www.cobo.com/developers/v2_cn/guides/webhooks-callbacks/webhook-event-type#webhook-事件类型)。

## 使用 Fee Station 的优势

下表展示了使用 Fee Station 前后在链上费用管理等方面的差异，帮助你直观了解其带来的优势：

| 功能维度 | 使用 Fee Station 前          | 使用 Fee Station 后                                    |
| ------------ | -------------------------------- | ---------------------------------------------------------- |
| Gas 准备     | 每条链都需要手动准备 Gas Token   | 可充值 Gas Token 或美元稳定币，统一由 Fee Station 自动代付 |
| 代付策略     | 只能人工操作                     | 可配置交易地址 Gas Token 不足时代付或始终代付                |
| 费用结算     | 多链多币种分散记录，难以统一核算 | 使用同一币种与单一账户结算各类费用，账务更直观                       |
| 失败交易     | Gas 不足导致交易失败风险高       | 自动检测并补足 Gas，显著降低失败率                         |
| 维护成本     | 人工操作频繁、耗时               | 一次配置即可自动运行，减少维护工作                         |
| 数据追踪     | 缺乏统一的费用记录               | 可在 Fee Station 导出完整充值与支出记录                    |

## 支持充值的代币类型

### 美元法币
充值美元法币即可覆盖多链手续费与平台费用，无需准备 Gas Token，亦无需预先充值或转入数字货币资产。

### 美元稳定币

只需充值美元稳定币，即可覆盖多链手续费，无需为每条链单独准备 Gas Token。

| --------- | ------------------------------ |
| TRON        | USDT                         |
