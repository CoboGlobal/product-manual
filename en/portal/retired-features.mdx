<Note>This page records features that Cobo has permanently retired. It is kept so that older links and bookmarks resolve to an explanation rather than an error page.</Note>

## Smart Contract Wallets (Safe&#123;Wallet&#125;)

Smart Contract Wallets, including the Safe&#123;Wallet&#125; wallet subtype, have been permanently retired. Cobo Portal no longer provides a way to create or manage them, and their documentation has been withdrawn from this site.

On-chain transaction policies were built specifically for Smart Contract Wallets and have been retired along with them. [Transaction policies](/en/portal/risk-controls/tx-policies-overview) continue to apply to all wallet types.

Cobo Portal offers Custodial Wallets, MPC Wallets, and Exchange Wallets. For an overview of what each one is for, see [Introduction to Cobo Portal](/en/portal/introduction).

<Info>If you use Cobo Portal to manage Signers and message-signing policies for a Safe&#123;Wallet&#125; that you created yourself on the Safe website, that is a separate capability and is unaffected. See [Set up risk controls for Safe&#123;Wallet&#125; message signing](/en/portal/risk-controls/safe-risk-controls).</Info>
