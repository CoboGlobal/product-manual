**Applicable to: Custodial Wallets (Web3 Wallets), MPC Wallets**

If an auto-sweep task or transaction is not progressing as expected, first open the wallet's auto sweep settings in Cobo Portal and review the relevant task and transaction details. Check the displayed status and failure reason before taking action.

Common failure categories include:

- The deposit address has insufficient token balance or gas.
- The estimated network fee exceeds the configured [network fee limit](/en/portal/auto-sweep-settings#modify-network-fee-limits-for-sweep-transactions).
- Another sweep task is already in progress for the same wallet or address.
- The sweepable amount is below the configured [minimum sweep amount](/en/portal/auto-sweep-policy-edit).
- On TRON, the address has insufficient energy.
- The transaction encounters an on-chain execution failure.

If a transaction remains unconfirmed because its fee is too low, locate it in the wallet's transaction history. If the chain and transaction support RBF (Replace By Fee), accelerate it through RBF. To reduce future delays during fee spikes, configure an appropriate network fee limit and [enable automatic RBF for sweep transactions](/en/portal/auto-sweep-settings#automatically-trigger-rbf-acceleration-for-sweep-transactions).

In the WaaS 2.0 API, `failed_reasons` is a free-text field on a sweep task. Treat it as diagnostic text, not as a stable enumerated error-code table.

If the issue persists, please prepare the transaction hash (TxHash), chain, and token information, then contact Cobo Support (help@cobo.com) for assistance.
